Smart Job Skill Analyzer

A Python-based web application that analyzes uploaded resumes against selected job roles to identify matched and missing skills. It provides career recommendations, estimated salary ranges, company matching information, and a skill-demand visualization to help users understand their skill gaps and career development opportunities.

Technologies Used
Python, Streamlit, Pandas, PyPDF2, Matplotlib.

Key Features
Upload and analyze PDF resumes.
Identify matched and missing skills for selected job roles.
Generate career recommendations and next steps.
Display estimated salary ranges and company matching information.
Visualize skill-demand scores and summarize skill gaps.

How to Run
1. Install the required packages using `pip install -r requirements.txt`.
2. Run `streamlit run job_app.py`.
3. Open the local URL displayed in the terminal.
